第一章：深入理解Quantumult的核心功能

要充分利用Quantumult，首先需要了解它的核心架构和功能模块。Quantumult的设计理念是"把控制权交给用户"，这意味着你可以根据自己的需求定制几乎所有的网络行为。

1.1 代理协议支持

Quantumult支持多种主流的代理协议，包括Shadowsocks、ShadowsocksR、V2Ray、Trojan等。这意味着无论你的机场提供哪种协议的服务，Quantumult都能完美适配。特别是对于V2Ray和Trojan这类较新的协议，Quantumult的优化做得相当出色，能够充分发挥这些协议在抗封锁方面的优势。

1.2 分流规则引擎

Quantumult最强大的功能之一就是其灵活的分流规则系统。通过配置规则，你可以实现"国内直连、国外代理"的智能分流模式。例如，你可以设置所有访问中国大陆网站（如百度、淘宝）的流量直接连接，而访问Google、YouTube等海外网站时则通过代理服务器转发。这种分流机制不仅提升了访问速度，还能有效节省代理流量。

1.3 网络抓包与调试

对于开发者或网络爱好者来说，Quantumult内置的网络抓包功能非常实用。你可以实时查看每个连接请求的详细信息，包括请求头、响应数据、耗时等。这对于排查网络问题、分析API接口调试等场景非常有帮助。

1.4 流量统计与监控

第三章：Quantumult的详细配置教程

现在让我们进入实践环节，一步步完成Quantumult的安装和配置。

3.1 安装与初始设置

在App Store中搜索"Quantumult"，下载安装后打开应用。首次启动时，Quantumult会请求VPN权限，这是正常现象，请点击允许。然后进入"设置"菜单，开启"启动时自动连接"选项，这样每次打开应用都会自动建立代理连接。

3.2 添加免费机场节点

方法一：手动添加 1. 打开Quantumult，点击底部的"节点"标签。 2. 点击右上角的"+"号，选择"手动添加"。 3. 根据机场提供的信息，填写服务器地址、端口、协议类型（如SS、VMess等）、密码或UUID。 4. 点击"保存"即可完成添加。

方法二：订阅链接导入 大多数机场都提供订阅链接（URL），这可以让你批量导入所有节点： 1. 在机场官网复制订阅链接。 2. 在Quantumult的"节点"页面，点击"+"号，选择"订阅"。 3. 粘贴订阅链接，Quantumult会自动解析并导入所有节点。 4. 建议开启"自动更新"选项，这样当机场更新节点时，Quantumult会自动同步。

3.3 配置分流规则

这是Quantumult的精髓所在。合理的分流规则可以让你在访问国内网站时直连（速度快），访问海外网站时走代理（突破限制）。

使用默认规则：Quantumult内置了基础的国内/国外分流规则，适合新手直接使用。

自定义规则：进入"设置"→"规则"→"自定义规则"，你可以添加特定的域名或IP规则。例如： ```

直连规则（不走代理）

DOMAIN-SUFFIX,baidu.com,DIRECT DOMAIN-SUFFIX,qq.com,DIRECT

代理规则

DOMAIN-SUFFIX,google.com,PROXY DOMAIN-SUFFIX,youtube.com,PROXY ```

策略组配置：Quantumult支持策略组，你可以创建多个策略组（如"流媒体"、"社交"等），每个策略组包含特定的节点，然后根据不同的访问需求选择不同的策略组。

3.4 高级功能：网络抓包与流量控制

抓包功能：在"设置"→"抓包"中开启后，Quantumult会记录所有经过代理的HTTP/HTTPS请求。你可以查看请求的完整信息，用于调试或分析。

流量控制：在"设置"→"流量"中，你可以查看每个节点的实时流量速度，并设置流量告警阈值。当流量使用达到设定值时，Quantumult会发出提醒。

第四章：常见问题与解决方案

4.1 连接不上节点怎么办？

首先检查节点是否在线（可以通过其他设备或工具测试）。其次，尝试切换不同的协议或端口。如果仍然无法连接，可能是你的IP被机场封禁，可以尝试更换网络环境（如切换到移动数据）。

4.2 速度很慢如何优化？

  • 尝试切换其他节点，选择延迟更低的服务器。
  • 检查是否开启了不必要的分流规则，导致所有流量都走代理。
  • 在"设置"中开启"快速打开"选项，减少握手时间。
  • 关闭后台不必要的应用，释放网络资源。

4.3 免费机场安全吗？

这是用户最关心的问题。使用免费机场时，请注意： - 避免在代理状态下登录敏感账户（如网银、邮箱）。 - 不要在代理状态下输入个人信息。 - 尽量选择支持HTTPS加密的节点。 - 有条件的用户建议使用付费机场，安全性更有保障。

FAQ

Trojan 的伪装域名如何正确配置？
伪装域名必须真实可访问且证书有效，否则客户端无法建立连接。正确配置可隐藏真实流量特征，降低被封锁和检测风险，提高节点安全性和长期可用性。
V2Ray 中的 alterId 是什么，现在还有必要配置吗？
alterId 曾用于 VMess 的用户混淆机制以防止重放攻击，但在 V2Ray 新版本与 VLess 出现后，alterId 已不再推荐使用。现代配置多使用 UUID 或直接迁移至 VLess/XTLS 以获得更好性能与安全性。
VLESS + XTLS 如何在高延迟网络中优化连接？
XTLS 模式通过减少握手和加密开销降低延迟。结合策略组和多节点切换，可在高延迟或不稳定网络环境下保证网页浏览、视频播放和游戏连接稳定，提高整体体验。
SSR 是否还值得使用？
虽然 SSR 的开发早已停止，但由于它配置简单且部分节点仍然兼容，仍有一定使用场景。不过建议用户逐步迁移到更安全的新协议如 VLESS 或 Trojan，以获得更佳性能与隐蔽性。
V2Ray 如何通过策略组优化访问速度？
策略组允许用户将节点按延迟、地域或用途分组。结合路由规则，V2Ray 会自动选择最优节点处理流量，提升访问速度并降低延迟，尤其在访问海外网站时效果明显。
VMess 协议的核心优势是什么？
VMess 是 V2Ray 项目的核心协议，支持加密、认证和多路复用功能。它能有效防止中间人攻击和流量识别，具有较高的安全性和灵活性，是目前科学上网中最常见的加密协议之一。
VMess 的 WebSocket + TLS 配置有哪些好处？
WebSocket + TLS 可伪装为普通 HTTPS 流量，增强抗封锁能力和隐蔽性。结合域名伪装和策略组使用，可以在高封锁网络中保持稳定、高速和安全的网络访问体验。
Mihomo 节点分组如何自动切换最佳节点？
将节点按延迟、地区或用途分组，并启用策略组功能，系统会根据节点延迟和健康状态自动切换到最佳节点，保证网页、视频和游戏连接稳定流畅。
Potatso Lite 的节点测速功能有何局限？
Potatso Lite 节点测速只能显示延迟，无法测出带宽或实际下载速度。此外，测速结果受网络波动影响较大，建议结合实际使用体验来判断节点性能。
Sing-box 如何实现域名精确分流？
Sing-box 支持按域名匹配流量，将不同应用流量分配到指定节点。结合策略组使用，可自动选择最优节点，提高访问速度和网络稳定性，实现精确流量管理。
